# AI Radar

Одностраничный дашборд трендов в мире ИИ за последние 7 дней. Собирает данные из трёх источников:

| Источник | Что показывает | Ключ |
|---|---|---|
| GitHub | Репозитории по темам `ai`, `machine-learning`, `llm`, созданные за 7 дней | не нужен |
| HackerNews | Посты про ИИ с наибольшим числом очков за 7 дней (Algolia HN API) | не нужен |
| YouTube | Видео об ИИ с наибольшим числом просмотров за 7 дней (YouTube Data API v3) | **нужен** |

Стек: HTML + CSS + vanilla JS, без сборки и зависимостей.

## Запуск

Нужен любой статический сервер. Проще всего Python:

```bash
python -m http.server 8765
```

Затем откройте http://localhost:8765/index.html.

GitHub и HackerNews работают сразу. Для YouTube настройте ключ (см. ниже), без него эта вкладка показывает подсказку, а остальные работают как обычно.

## Настройка ключа YouTube

### 1. Получите ключ

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и создайте проект (или выберите существующий).
2. Включите **YouTube Data API v3**: «APIs & Services» → «Library» → найдите YouTube Data API v3 → «Enable».
3. «APIs & Services» → «Credentials» → «Create credentials» → «API key».
4. Ограничьте ключ (рекомендуется, потому что ключ виден в браузере):
   - «Application restrictions» → «Websites» → добавьте `http://localhost:8765/*`;
   - «API restrictions» → «Restrict key» → только YouTube Data API v3.

### 2. Передайте ключ приложению

Есть два способа, подойдёт любой.

**Способ A: поле на вкладке YouTube.** Откройте приложение, вставьте ключ в поле «Ключ YouTube Data API v3» и нажмите «Сохранить и загрузить». Ключ сохранится только в localStorage вашего браузера. Сменить его можно кнопкой «Сменить ключ», которая появляется при ошибке.

**Способ B: файл `config.js`.** Скопируйте образец и впишите ключ:

```bash
cp config.example.js config.js
```

```js
window.RADAR_CONFIG = {
  youtubeApiKey: 'ВАШ_КЛЮЧ',
};
```

`config.js` указан в `.gitignore` и в репозиторий не попадает. Не коммитьте ключ.

Если заданы оба способа, приоритет у ключа, введённого в интерфейсе.

### Квота

По умолчанию у YouTube Data API 10 000 единиц в сутки. Одна загрузка вкладки стоит около 101 единицы (поиск 100 и запрос статистики 1), то есть примерно 99 обновлений в день. Загрузка выполняется один раз при открытии страницы.

## Как считается рост

Прямого «прироста за неделю» ни один из API без ключа не отдаёт, поэтому темп считается как значение в день с момента публикации (не меньше суток):

- GitHub: звёзды в день с момента создания репозитория. Старые проекты, которые набирали звёзды на этой неделе, не попадают, потому что берутся только репозитории, созданные за 7 дней;
- HackerNews: очки в день;
- YouTube: просмотры в день.

## Возможности

- Вкладка «Обзор»: три колонки рядом, по 12 лучших карточек, ссылка «Показать все N».
- Вкладки GitHub, YouTube, HackerNews с полным списком.
- Поиск по всем источникам сразу: все слова запроса должны встретиться в заголовке или описании.
- Сортировка по росту, дате и популярности.
- Тёмная и светлая тема, выбор запоминается.

## Тесты

```bash
node --test test.js
```

Тесты покрывают чистую логику из `lib.js`: нормализацию данных источников, расчёт темпа, поиск, сортировку, форматирование чисел и дат.

## Ограничения и частые проблемы

- **GitHub: ошибка лимита.** Без токена Search API разрешает около 10 запросов в минуту, а одна загрузка делает 3. Подождите минуту и нажмите «Повторить».
- **YouTube: «Ключ не принят».** Проверьте, что включён YouTube Data API v3 и что в ограничении по сайтам указан именно тот адрес и порт, с которого открыто приложение.
- **В консоли 404 на `config.js`.** Это нормально, файл необязателен.
- **Ключ виден в браузере.** Это неизбежно для приложения без сервера, поэтому ограничивайте ключ по адресу и по API.
